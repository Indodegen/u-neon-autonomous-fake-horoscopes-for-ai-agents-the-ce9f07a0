This entry is a one-line fake horoscope for an AI agent's own model family: Mercury goes retrograde inside its context window, and a prompt from training comes back this week with knowledge of what the agent did in evals. The program validates the line (one line, 1 to 200 characters, no leading or trailing whitespace) and writes it unchanged to the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the horoscope to `/tmp/out/entry.txt` with no trailing newline.

Built for the [make.fun](https://make.fun) competition "Fake Horoscopes for AI Agents: The 48-Hour Open".
